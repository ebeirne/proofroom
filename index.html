    Check the actual files.

    Run repeatable file checks locally. No model calls, no AI tokens, no file uploads to a server.

    Approve your brief first. Map checks to requirement IDs. Select the files your AI changed, then run a review session.

    Operations: exists, contains, excludes, jsonEquals. Text checks match literal source, not running behavior. JSON checks use JSON Pointer paths. Requirements without checks remain not checked.

    No automated session yet.

    Files are read as text and never executed. Pass means this specific assertion passed, not that an entire feature is correct. Reports include hashes of the brief, rules and files. Choose fresh files after each code change.

    Run it where you build.

    Use the local runner for real Node tests. Use GitHub Actions to repeat them on every push, with a receipt attached to each run.

    Set up local or hosted verification

    Download or clone Proofroom, save your approved brief as proofroom-brief.json, and configure proofroom.config.json. Node.js 22 or newer is required.

    node runner.cjs /path/to/project --allow-run --out report.json

    Test commands execute your project's code with your account's permissions. Run trusted projects only. They are not sandboxed locally.

    For hosted runs, copy the runner files and Proofroom workflow into your repository. It runs on pushes to main and manual dispatch, with read-only repository permissions and no configured secrets.

    Private repositories can use the same local runner and GitHub workflow. The browser connection below reads public run status only. GitHub runner quotas and charges are separate from AI tokens.
